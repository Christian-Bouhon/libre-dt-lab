
=head1 NAME

libre-dt-lab-generate-cache - update libre-dt-lab's thumbnail cache

=head1 SYNOPSIS

    libre-dt-lab-generate-cache [-h, --help; --version] [-m, --max-mip <0-7>] [--core <libre-dt-lab options>]

=head1 DESCRIPTION

B<libre-dt-lab> is a digital photography workflow application for B<Linux>, B<Mac OS X> and several other B<Unices>.
It's described further in L<libre-dt-lab(1)|libre-dt-lab(1)>.

B<libre-dt-lab-generate-cache> updates libre-dt-lab's thumbnail cache.
You can start this program to generate all missing thumbnails in the background when your computer is idle.

=head1 OPTIONS

All parameters are optional.
If started without parameters B<libre-dt-lab-generate-cache> uses reasonable defaults.

=over

=item B<-h, --help>

Gives usage information and terminates.

=item B<--version>

Gives copyright and version information and terminates.

=item B<< --min-mip <0-7> >>

=item B<< -m, --max-mip <0-7> >>

B<libre-dt-lab> can handle and store thumbnails with up to eight different resolution steps for each image.
These parameters define which maximum resolution should be generated and default to a range of B<0-2>.
There is normally no need to generate all possible resolutions here; missing ones will be automatically generated by libre-dt-lab the moment they are needed.
When asked to generate multiple resolutions at once, the lower-resolution images are quickly downsampled from the highest-resolution image.

=item B<< --min-imgid <N> >>

=item B<< --max-imgid <N> >>

Specifies the range of internal image IDs from the database to work on.
If no range is given, B<libre-dt-lab-generate-cache> will process all images from the entire collection.

=item B<< --core <libre-dt-lab options>  >>

All command line parameters following B<--core> are passed
to the libre-dt-lab core and handled as standard parameters.
See L<libre-dt-lab(1)|libre-dt-lab(1)> for a detailed description of the options.

=back
