
=head1 NAME

libre-dt-lab-cltest - check if there is a usable OpenCL environment for libre-dt-lab to use

=head1 SYNOPSIS

    libre-dt-lab-cltest

=head1 DESCRIPTION

B<libre-dt-lab> is a digital photography workflow application for B<Linux>, B<Mac OS X> and several other B<Unices>.
It's described further in L<libre-dt-lab(1)|libre-dt-lab(1)>.

B<libre-dt-lab-cltest> checks if there is a usable OpenCL environment on your system that libre-dt-lab can use.
It emits some debug output that is equivalent to calling B<libre-dt-lab -d opencl> and then terminates.
